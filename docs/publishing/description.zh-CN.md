# 荔枝天赋：这一战，用对天赋

换了副本，又要翻聊天记录找天赋字符串？荔枝天赋把 WCL 高表现方案整理到原生天赋页旁边。打开天赋页，找到副本或首领，双击应用。

## 打什么本，就选什么方案

大秘境按副本查看，团本可以切换英雄和史诗难度。悬停查看记录信息，行末菜单保留 WCL 来源与字符串复制入口，选方案时也能知道它从哪里来。

## 自己的天赋，也放在一起

导入朋友分享的字符串，或保存当前天赋；名称、图标、字符串和场景关联在同一个编辑页完成。一套方案可以关联多个副本或首领。导入和保存只加入方案库，不会立刻切换天赋。

## 技能摆放，跟着方案走

在方案菜单中启用独立动作条，下次应用时使用这套方案自己的布局。不启用时使用该专精首次启用时记录的默认布局。不会修改你的按键绑定。

## 到地方，提醒你准备

进入副本或到达可识别的首领区域时，提示可用的推荐与个人关联方案。点击“切换”才应用；战斗中收起，已使用对应方案时不提示。不需要时，在右上角齿轮设置关闭提醒。

## 安装后，打开天赋页

正式服 12.1 独立插件，无需荔枝启动器或 WCL 密钥。将 LycheeTalent 和全部 LycheeTalent_Data_* 文件夹安装到正式服 Interface/AddOns，启用后打开原生天赋页，或输入 /lt。职业数据按需加载。

当前 1.0.0 随包提供 2026-09-26 采集的 1,815 条推荐组合，覆盖 13 职业、40 专精。数据随插件更新，推荐供实战准备参考，仍需结合装备、队伍和打法选择。
