Lychee Talent — the right build for your next encounter

Open your talent window, find the dungeon or boss and double-click to apply. Lychee Talent brings builds drawn from high-performing WCL records into a compact panel beside the native talent tree.

Plan for the next pull

Browse Mythic+ dungeons or Heroic/Mythic raid encounters. Inspect record details and open the WCL source from the row menu.

Keep your own builds close

Import a friend's string or save your current talents. Edit the name, icon, talent string and encounter links in one place. Importing and saving do not apply the build.

Bring the right action bars

Enable independent action bars for builds that need a different layout. Otherwise, use the specialization's shared layout. The preference takes effect when applying a build; key bindings are unchanged.

A reminder when you arrive

Matching recommendations and linked personal builds can appear on reaching an encounter. Talents change only when you click Switch. Reminders hide in combat and can be disabled from the settings gear.

Install and open talents

For Retail 12.1.5. Install LycheeTalent and all LycheeTalent_Data_* folders under Interface/AddOns, then open talents or type /lt. No Lychee Launcher or WCL credentials required; class data loads on demand.

The current package contains 1,856 builds across 13 classes and 40 specializations, collected on 2026-10-13 (UTC), with a separate Holy Paladin Mythic+ refresh on 2026-10-14. Data updates with the addon. Recommendations are a starting point; gear, group and strategy still matter.
